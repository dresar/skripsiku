Tentang Sistem

Sistem Deteksi Mutu Lateks Portabel Berbasis IoT dengan implementasi algoritma thresholding pH pada ESP32 untuk smart monitoring.

Sistem ini menerima data dari sensor (pH, TDS, suhu) via MQTT, menyimpan ke database, dan menampilkan dashboard realtime serta riwayat dan statistik.

Teknologi

  • • ESP32 — Mikrokontroler & publisher MQTT
  • • MQTT — Protokol messaging
  • • FastAPI — Backend REST API & WebSocket
  • • SQLite — Database
  • • Dashboard — Jinja2, TailwindCSS, Chart.js
